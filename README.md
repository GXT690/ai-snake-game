# 🐍 AI智能贪吃蛇 - AI Snake Game

一款基于AI驱动的贪吃蛇对战游戏，实时展示AI决策过程，支持玩家VS AI和AI VS AI两种模式。

## ✨ 项目特性

### 🧠 AI决策系统
- **A*寻路算法**：AI使用经典的A*路径规划算法预测最优移动路径
- **实时路径预测**：展示AI找到的到达食物的最短路径
- **智能避障**：自动避开墙壁和自身身体碰撞
- **决策可视化**：实时展示AI的思考过程和决策依据

### 🎮 游戏模式
- **玩家 VS AI**：人类玩家与AI对战
- **AI VS AI**：两台AI自动对战

### 📊 数据分析面板
- 实时显示AI命中率和决策速度
- 记录AI获胜次数和对战统计
- 可视化路径预测和方向选择

### 🎨 视觉效果
- 像素风格复古设计
- 粒子特效增强游戏体验
- 深色主题，护眼舒适

## 🎯 游戏操作

### 玩家控制
- **方向键** 或 **WASD**：控制贪吃蛇移动方向
- **玩家蛇**：绿色（左侧）
- **AI蛇**：红色（右侧）

### 游戏规则
- 吃到食物得分+10
- 撞墙或撞到自己则游戏结束
- AI会自动寻找最优路径获取食物

## 🤖 AI算法说明

### A*寻路算法实现

本项目使用经典的A*路径规划算法，核心公式：

```
f(n) = g(n) + h(n)
```

- **g(n)**：从起点到节点n的实际距离
- **h(n)**：从节点n到终点的启发式估计（曼哈顿距离）
- **f(n)**：节点n的总代价

### 算法流程
1. 初始化开放列表，将起始节点加入
2. 循环：从开放列表中选取f值最小的节点
3. 检查是否到达目标（食物位置）
4. 遍历相邻节点，计算代价并更新路径
5. 重复直到找到路径或开放列表为空

### 安全策略
当无法找到通往食物的路径时，AI会执行以下策略：
1. 寻找所有安全方向（不撞墙、不撞自己）
2. 优先选择离边界最远的方向
3. 避免进入死胡同
